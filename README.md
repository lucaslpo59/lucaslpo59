## Olá, eu sou o Lucas

Trabalho com suporte e manutenção de computadores, redes e servidores, e desenvolvo sistemas por conta própria. Comecei consertando PCs e celulares numa assistência técnica e hoje mantenho servidores Linux em produção para os meus projetos.

Procuro uma vaga na área de **TI e suporte**.

### O que eu faço

- **Suporte e manutenção:** formatação, troca de peças, remoção de vírus, impressoras, atendimento ao usuário
- **Redes:** cabeamento, roteadores, IP/DHCP/DNS, diagnóstico de falhas, servidor local
- **Servidores Linux:** Ubuntu, Nginx, systemd, firewall, fail2ban, backup, deploy com git
- **Desenvolvimento:** dashboards, APIs em Node.js, apps Android, sites e automação com PowerShell e Python
